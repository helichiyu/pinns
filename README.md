# 单模型三损失相位恢复

本项目只训练一个未预训练 UNet。首轮输入是原图的 **Patterson map**，之后每轮将上一轮 UNet 输出 `detach` 后作为下一轮输入。

Patterson map 即 `P = IFFT(|F|²)`——把实测振幅取平方、所有相位置零后做逆变换，数学上就是物体自身的**自相关函数**。它不需要相位就能从实测振幅直接算出，比随机相位携带真实结构信息（物体尺寸、内部间距）。三处实现细节：

- **挖洞复用振幅损失的低频圆盘**（`AMPLITUDE_DC_RADIUS = 3.0`，29 个频点），即实际算的是 `P = IFFT(|F|² · mask)`。语义与损失一致：输入里看不到的低频，损失里也不罚。
- **min-max 归一化到 [0, 1]**。真正的自相关恒非负，但挖掉频谱分量后 IFFT 不再保证这一点（实测约一半像素为负），所以不能截零。代价是对比度偏低——原点峰独占区间上端，99% 的像素挤在 0.11~0.18 的窄带里（随机相位初始化的标准差是 0.154，Patterson 只有 0.034）。结构信息仍在，第一层卷积后的 `InstanceNorm2d` 会重新拉开尺度。
- **fftshift 到画布中心**。不 shift 的话周期延拓会把自相关切成四块贴在四个角，而源图物体居中、第 2 轮起的输入（上一轮输出）也居中。

两点需要知道的性质：自相关支撑是物体的 2 倍，`expand=1` 时画布不够大会卷绕自叠，要干净的 Patterson 需要 `expand≥2`；Patterson 完全确定，所以 `--seed` 只影响网络权重初始化，不再影响输入。

训练不使用 HIO、RAAR，也不使用原图轮廓的位置或形状作为监督。

## 损失函数

1. 振幅损失：**排除以直流为中心的低频圆盘**（半径 `AMPLITUDE_DC_RADIUS = 3.0`，共 29 个频点），其余频点（含高频）全部参与，在归一化对数振幅域计算 MSE，防止低频大数值主导。直流点等于全图像素总和，紧邻它的几圈低频同样是整幅谱里数值最大的一批，留着损失会几乎只在调整整体亮度和大尺度明暗；高频虽幅值小、含噪，但决定重建锐度，不排除。`fft2` 没有 `fftshift`，直流在 `[0, 0]`、低频绕到四个角，所以频率距离取环绕后的最小值，而不是直接切一块方块。挖洞只发生在算损失时，训练本身用的仍是完整输出，没有任何频域裁剪。归一化基准取**挖洞后**参与损失的频点里的最大振幅——用被挖掉的直流当基准会把剩余频点全挤在 `log1p` 的近零段（实测两者可差二十倍以上），动态范围浪费掉。
2. 轮廓内直方图损失：只在轮廓内比较原图与输出的分布，用**等点数分箱**（quantile / equal-frequency binning）——把轮廓内 `k` 个像素排序后切成 `B` 段、每段点数相等，比较 `B` 个分位点的**像素值**。每箱点数相等，所以能比的只有箱边界（分位值）；比箱内计数是常数，没意义。目标分位值取自源图轮廓内的像素值（训练前算一次并缓存），预测分位值取自输出**自己的**轮廓内像素值——不用源图轮廓的位置，否则等于把轮廓形状当成监督。两侧像素数严格相等，rank 一一对应，无需插值或长度补偿。
3. 背景损失：轮廓外的输出被约束为 0。轮廓是常量，网络不能通过扩大轮廓规避背景惩罚。

轮廓的算法分两侧：

- **源图侧**（训练前算一次）：高斯模糊 → 减去自身最低基线 → 峰值归一化 → 硬阈值二值化，得到 0/1 的 mask。数出其中 1 的个数记为 `k`，占比 `ρ = k / N` 只用于显示。减基线是为了避免整体亮度把轮廓撑到全图；阈值是相对峰值的比例，不随图片整体亮度漂移。
- **输出侧**（每轮）：高斯模糊 → 取前 `k` 个最亮像素置 1。像素数恒为 `k`，与源图轮廓严格相等。

锁 `k` 而不是锁 `ρ`：后者要经两次浮点取整，两边像素数会差几个。用 topk 的下标散射而不是阈值比较，也是为了这个严格性——并列值在阈值下会多圈几个像素。

直方图项的梯度链是「选像素 → `sort` → 固定 rank 下标 `gather` → MSE」，四步都原生可导：`sort` 反向时把 `sorted[j]` 的梯度按下标散射回原始位置，即"排在第 j 名的那个像素"领走这份梯度。因此每轮恰有 `B` 个像素直接收到直方图梯度，其余靠振幅与背景间接训练。代价是它不像 sigmoid 软 CDF 那样处处光滑：两像素值接近时排序可能交换，梯度会跳变——与 `topk_contour` 的离散性同类，Adam 能吸收。

mask 的 `requires_grad` 为 `False`，是纯常量，只当选择器用。它本身几乎处处梯度为 0、不可导，但两个消费者都只需要"选中哪些像素"这个信息，梯度经 `prediction` 本身回流到网络。原先的轮廓占比损失需要可导轮廓（它算 `d(contour.mean())/d(pred)`），而在 top-k 构造下占比恒等相等、该损失恒为 0，因此已删除。

图片统一采用反转后的工作表示：黑色背景为 0，物体为亮色。

参数说明：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--image` | `config.IMAGE_PATH` | 图片文件名 |
| `--expand` | `1` | 画布扩大倍数；`1`=不扩大，`2`=每维扩大 2 倍。**可为小数**（如 `1.5`）：扩大后的边长向下取整，随后统一 pad 到 16 的倍数（UNet 四级下采样，固定不可调），所以实际倍率会略高于名义值。例如 567（600×302）填 `1.5` 得到 464×912，实际约 1.54×1.52 |
| `--contour-sigma` | `config.CONTOUR_SIGMA` (16) | 高斯模糊半径，控制两侧轮廓提取的尺度（源图与每轮输出都用同一个值） |
| `--contour-threshold` | `config.CONTOUR_THRESHOLD` (0.20) | 源图轮廓的相对峰值阈值。**只在训练前用一次**，用来二值化源图 mask 并数出像素数 `k`；输出侧不用阈值，改按 `k` 取 top-k |
| `--share-histogram` | `config.SHARE_HISTOGRAM` (0.5) | 轮廓内直方图项的目标贡献占比 `w_hist`（相对振幅项，全程维持） |
| `--share-background` | `config.SHARE_BACKGROUND` (0.10) | 背景项的目标贡献占比 `w_bg` |
| `--iterations` | `config.ITERATIONS` (3000) | 训练轮数 |
| `--seed` | 无 | 随机种子 |
| `--cpu` | 关 | 强制 CPU |
| `--log-every` | `config.LOG_EVERY` (20) | 日志间隔 |

结果目录在训练结束、真要写文件时才创建（失败或被终止不会留下空目录），包含：`real_space.png`（原图 / 输出 / 叠加 / 误差）、`spectra.png`（振幅谱）、`support.png`（硬轮廓对比）、`convergence.png`（3×3 共 9 个指标面板）、`history.csv`、`metrics.csv`、`state.pt`。目录名的时间戳是训练开始时刻。

## 主要参数

集中在 `backend/config.py`：默认训练 3000 轮；轮廓参数为 `sigma=16.0`、阈值为基线校正后峰值的 `0.20`，以形成整个分子的连续概括外包络；等点数分箱的箱数 `HISTOGRAM_BINS = 100`（`docs/histogram_quantile_research.md` 第七节按统计规则推荐 256，现按实验需要下调为 100）。振幅损失不设近零振幅下限，只排除半径 `AMPLITUDE_DC_RADIUS = 3.0` 的中心低频圆盘（29 个频点）。离线指标及最终对比图会先消除平移和镜像歧义，再与原图比较。

三项损失用 Kendall 同方差不确定性加权（[arXiv:1705.07115](https://arxiv.org/abs/1705.07115)）组合，外层再乘固定的目标贡献比：

```
L = Σ_i  w_i · [ exp(-s_i) · L̂_i + s_i ]        L̂_i = L_i / L_i,0
```

`s_i = log σ_i²` 是**可学习参数**（三项都可学），初值 0，与网络参数进同一个 Adam、同一个学习率 `1e-4`（原文做法）。`exp(-s_i)` 是自适应权重，`+ s_i` 是阻止权重趋零的正则项。

两处与原式不同，各有其必要性：

- **各项先除以首轮实测值 `L_i,0`**。三项损失的原始量级差近四千倍（`567.png` 实测 `1 : 4756 : 5791`）——振幅是 `log1p` 压缩后 18 万个频点的 MSE，97.8% 的目标值小于 0.01，天然是 `1e-5`；直方图是 100 个像素值的 MSE；背景是全图 `pred²` 的均值。不归一化则 `s_i = 0` 的开局会把辅助项放大数千倍，而全黑解能让背景损失精确归零，大概率直接塌缩。归一化后 `L̂_i,0 = 1`，`s_i = 0` 正是原文初值，不需要额外的初始化步骤。
- **`w_i` 乘在方括号外**。对 `s_i` 求导时 `w_i` 被约掉，不动点仍是 `exp(-s_i) = 1/L̂_i`，但各项的实际加权贡献收敛到 `w_i` 本身，即**全程维持 `1 : w_hist : w_bg`**，而不是原式的三项等权。`w_i` 若乘进方括号内，不动点会让贡献收敛到 `w_i · L_i,0`，辅助项被压掉几千倍，退化成「振幅独占」——那正是 `docs/adaptive_weighting_research.md` 第 6.2 节记录的旧失败形态。

`w_i` 按各约束的可信度排定：振幅恒 `1`（唯一的硬数据）、轮廓内直方图 `0.5`、背景 `0.10`。背景最小，因为它是由网络自己输出的轮廓推出来的、最不可信，且权重过大会把整幅图压黑而塌缩。这两个常数是全局的，不需要按图片重调；前端第四行也可以逐组覆盖。

与先前固定权重方案的关系：旧式 `β_i = SHARE_i × L_amp,0 / L_i,0` 与本式首轮的有效权重 `w_i / L_i,0` 只差一个全局公因子 `L_amp,0`，而 Adam 对损失的全局缩放不敏感（`m/√v` 归一化）。所以**第一轮的网络更新与固定权重方案一致**，差异纯粹来自 `s` 可学：旧式只在第一轮标定一次、之后贡献比会漂走（实测 567 漂到 `1:1.74:0.69`、123 漂到 `1:0.15:0.06`），新式会持续把它拉回 `1:0.5:0.1`。

两点读数上的注意：

- **`total` 会变成负数**（首轮恰为 `Σ w_i = 1.60`，收敛后约 −6.6），因为 `+ s_i` 随 `s_i` 变负而下降。它衡量的是「`s` 走了多远」，不等于重建变好。`+ s_i` 对网络参数的梯度恒为 0，所以不影响训练。
- 前端实时曲线与 `__METRIC__` 改用**加权损失** `Σ w_i · exp(-s_i) · L̂_i`（不含 `+ s_i`）：它只反映损失下降，量级也与固定权重方案的 `total` 可比。
- `s_i` 的适配速度受 `lr = 1e-4` 限制：Adam 每步移动约 `1e-4`，30000 轮共约 3.0 nat，而实测各项损失需要 3.7~5.7 nat，所以**追不满**，实际贡献比会在目标值附近偏几倍（旧四损失结构那次滞后是 400 倍，当前结构约 2~6 倍）。`s_amplitude` / `s_histogram` / `s_background` 三列已记入 `history.csv`，可据此核算实际贡献比。

直方图接过了原轮廓占比项的抗塌缩主力位置（原为 `0.5`）：输出全黑时轮廓内的分位值全趋 0，而源图轮廓内全是中高亮度，分位值差距被最大化，罚得比占比那个标量约束更狠。施压分工也因此变干净——轮廓内由直方图 + 振幅负责，轮廓外由背景 + 振幅负责，不再有两项在全画布重叠拉扯。

Kendall 加权在**旧的四损失结构**上曾实测失败（`123.png` 重建塌缩成小亮点，IoU 0.117 → 0.0246），当时的结论是「结构性不适用」。硬轮廓改造后该失败机制已不成立，故重新启用——完整的重启依据与量化证据见 `docs/adaptive_weighting_research.md` 第九节。同一份文档还记录了另外两次失败（背景配 AL-PINNs 乘子导致 λ 无界增长把图压黑、占比项配乘子导致原始-对偶振荡）；占比项已随硬轮廓改动一并删除。注意该文档第一至八节记录的是历史实验，其中的四损失结构已不是当前实现。
