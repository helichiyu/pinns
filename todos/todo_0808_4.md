### 路径约定

- 服务端和训练脚本的 `sys.path[0]` 自动是 `backend/`，平级 import 无需 `__init__.py`。
- 服务端以根目录为 cwd 启动子进程，`123.png` / `results/` 等相对路径直接生效。

### train.py 统一参数

```
--image PATH           # 图片路径（默认 config.IMAGE_PATH）
--grayscale METHOD     # luminance | red_channel（默认 luminance）
--expand N             # 画布扩大倍数（默认 1=不扩大）
--iterations N         # 训练轮数
--output DIR           # 输出目录
--seed N               # 随机种子
--cpu                  # 强制 CPU
--log-every N          # 日志间隔
--stream-metrics       # 输出 __METRIC__ JSON 行（供服务端解析）
```

`load_source(path, device, grayscale, expand)` 统一三个管线的图片加载逻辑：
- 按 grayscale 方式生成灰度+反转
- expand>1 时居中放到 N 倍画布（零填充），display padding 返回 (0,0,0,0)
- expand=1 时只 pad 到 16 倍数，display padding 返回实际 pad 值
- 所有情况最后都 pad 到 16 的倍数（UNet 4 级下采样）

### server.py（tornado）

路由：
- `GET /` → `frontend/index.html`
- `GET /static/(.*)` → frontend 静态资源
- `GET /api/images` → 根目录 .png 文件列表
- `POST /api/preview` → `{image, grayscale, expand}` → base64 预览图
- `WS /ws` → 实验队列控制 + 输出流

WebSocket 协议：
- C→S: `{"type":"start","experiments":[{image,grayscale,expand,iterations}]}`
- S→C: `{"type":"exp_start","index":N,"config":{...}}`
- S→C: `{"type":"terminal","index":N,"text":"..."}`
- S→C: `{"type":"metric","index":N,"iteration":N,"total":F,"iou":F,"ssim":F}`
- S→C: `{"type":"exp_done","index":N,"output_dir":"..."}`
- S→C: `{"type":"all_done"}`

服务端逐行读取子进程 stdout：`__METRIC__` 前缀行解析为 metric，其余为 terminal。

### frontend（Apple 风格，原生 HTML/JS/CSS）

- 顶部：实验组数选择器（1~6），加减按钮
- 每组实验行：左=参数（图片下拉/灰度下拉/扩大输入/轮次输入/预览按钮），右=两条曲线（总损失 + IoU，canvas 绘制）
- 底部：终端输出（全宽，等宽字体，自动滚底）+ Start 按钮
- 配色取 DESIGN.md：#ffffff 画布 / #f5f5f7 parchment / #0066cc Action Blue / #1d1d1f ink
