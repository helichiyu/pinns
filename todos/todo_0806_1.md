## Reviewed Network Design

Let `A` be the complete fixed target Fourier amplitude and `x_t` the real-space state at outer iteration `t`.

1. Initialize `x_0` from the inverse FFT of `A` and a random phase.
2. Compute `X_t = FFT(x_t)`. Construct `X'_t = A * exp(i * angle(X_t))` at every frequency. When `X_t` is zero, use zero phase. The real part of `IFFT(X'_t)` is the full-amplitude projected state `q_t`.
3. Feed `[x_t, q_t]` to one U-Net. The U-Net architecture is otherwise identical to the existing model and emits the next `[0, 1]` state `x_(t+1)`.
4. Apply the existing four-part objective to `x_(t+1)`, update U-Net parameters, and retain the current detached state update for the next outer iteration.

The projection is a complete-amplitude, measurement-space operation used only as a second network input. The first proposal does not claim the U-Net output itself has exact amplitude consistency, because its sigmoid output can alter the spectrum; the unchanged amplitude loss still enforces data consistency.

`amplitude_mask` is not used in the projection. It excludes DC and weak-amplitude coefficients from the current loss, and is retained only unchanged for the first controlled architecture comparison.

## Adaptive Weighting Design For Review

The four raw terms are `L_amp`, `L_hist`, `L_bg`, and `L_area`. The proposed first adaptive method does not make weights ordinary trainable parameters. Instead, it uses gradient magnitudes as a feedback signal:

1. Fix `w_amp = 1` after normalizing the amplitude term by its initial reference scale. The amplitude measurement remains the anchor and can never be disabled by the weighting mechanism.
2. At an update interval `K`, calculate `g_i = ||gradient_theta(L_i)||` for every raw term using the current U-Net parameters.
3. For each existing auxiliary term, calculate the target ratio `r_i = clamp(c_i * g_amp / (g_i + epsilon), r_min, r_max)`, where `c_i` is an approved target gradient fraction.
4. Update its weight slowly: `w_i <- (1 - rho) * w_i + rho * r_i`. Use the total `L = L_amp + w_hist * L_hist + w_bg * L_bg + w_area * L_area` between updates.

This is a scalar, no-new-image-information adaptation of the Learning Rate Annealing / gradient-balancing idea. It balances update influence, not raw loss values. The constants `K`, `rho`, `c_i`, `r_min`, and `r_max` must be approved and logged; it is not parameter-free.

Do not optimize `w_i` with Adam in the same minimization direction as U-Net parameters. With nonnegative weights, minimizing `sum(w_i * L_i)` drives positive-loss weights toward zero. A softmax parameterization only forces competition and can still suppress useful terms.

The later augmented-Lagrangian candidate is only the scalar area equality `C_area = contour.mean() - target_area_ratio`. Its outer-loop objective is `L_main + lambda * C_area + 0.5 * beta * C_area^2`, followed by ascent `lambda <- lambda + beta * C_area`. Histogram matching is a statistical preference rather than a feasibility constraint and must remain an ordinary weighted loss. Background is also initially retained as a bounded weighted penalty because an exact zero target may be physically incompatible with blurred edges or noise.
