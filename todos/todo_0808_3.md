## 振荡根因（调研结论）

主因是原始-对偶鞍点振荡：θ 梯度下降、λ 梯度上升交替进行，在 r_area≈0 的鞍点附近
形成互相追逐的极限环（与 GAN 的 min-max 振荡同源）。λ 是纯累积（λ += η·r，无阻尼无衰减），
即使 r 已很小也持续扰动 θ；θ 滞后一步反应使 r 翻号、λ 过冲，ping-pong。
`dynamic_contour` 的陡 sigmoid（斜率 12）+ 每步变动的 peak 归一化放大了 r 的噪声。

关键：振荡来自 λ 这个对偶变量，不是来自权重大小。去掉 λ（固定权重）即消除反馈环，
无论 SHARE 取多少都不再振荡。

## 实施方案

四项损失统一为固定权重罚项，权重由首步损失自动标定：

```
L = L_amp + β_hist·L_hist + β_bg·L_bg + β_area·L_area
β_i = SHARE_i × L_amp,0 / L_i,0
```

- `losses.py`：`AugmentedLagrangian` → `CalibratedWeights`（只剩 calibrate + total，
  无 λ、无残差、无 update_multipliers）；删除 `area_ratio_residual`。
- `config.py`：`SHARE_AREA_RATIO` 1.0 → 0.5；删除 `AL_LAMBDA_RATIO`。
- `config_projected_123.py`：import 清单去掉 `AL_LAMBDA_RATIO`。
- 三个 pipeline：改用 `CalibratedWeights`，删残差/乘子相关行与 history 键，修正打印索引。
- `visualization.py`：`plot_convergence` 删 `r_area_ratio`、`lam_area_ratio` 两个面板。
