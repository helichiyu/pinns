## Design

### Data representation and recurrent input

The image is inverted into the existing working representation: its background is 0 and the object has positive intensity. The target Fourier amplitude is computed once. Random phase is used only for the initial IFFT image. At iteration `t`, the UNet input is the detached output from iteration `t - 1`; the first input is the random-phase IFFT result.

### Amplitude loss

Compute the Fourier amplitude of the current output. Exclude the DC element and amplitudes below `eps * max(target_amplitude)`. Compare `log1p(amplitude / max(target_amplitude))` with MSE, so very large low-frequency values cannot dominate the loss.

### Histogram loss

Compare the current output's complete-image intensity distribution directly against the inverted source image's complete-image distribution. Do not perform histogram matching and do not change output values. Use a differentiable soft CDF or soft histogram distance, because hard histogram binning has no useful gradient. Background pixels are intentionally included.

### Dynamic contour background loss

On every iteration, blur the current output using the old project's Gaussian-blur plus threshold method, with fixed coarse parameters. Convert the thresholded result to a soft contour. Stop gradients through that contour, then penalize the squared current output outside it. This replaces the old HIO/RAAR background constraint without leaking any source-image contour information. Parameters remain fixed throughout training; no shrinkwrap refinement or adaptive schedule is used.

### Loss and reporting

Use `L = w_amp * L_amp + w_hist * L_hist + w_bg * L_background`. Record all four loss values. Produce `real_space.png` containing inverted source, final output, color overlay, and absolute error; `spectra.png` with centered log amplitude spectra; `support.png` with the final dynamic contour only; `convergence.png` with loss and offline evaluation curves; and `history.csv`.
