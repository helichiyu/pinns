## Requirements

Kendall homoscedastic-uncertainty auto-balancing scheme in **all three training pipelines**, so that

Research basis: see `adaptive_weighting_research.md` (Section 4). This method resolves the prior
warning in `todo_0806_1.md` (Phase 3B) against jointly minimized weights, because the `+ s_i`
regularizer prevents the collapse-to-zero failure mode.

Network architecture (`model.py`, `model_projected_123.py`) is intentionally **not** changed in this
TODO, to keep the weighting change independently verifiable. Architecture observations are documented

## Assumptions And Boundaries

- The four raw loss functions (`normalized_log_amplitude_loss`, `soft_histogram_cdf_loss`,
  `background_loss`, `contour_area_ratio_loss`) stay exactly as defined in `losses.py`.
- The learned log-variance parameters `s_i` are the only new trainable parameters.
- `s_i` are optimized by the same Adam optimizer as the U-Net parameters (safe because of the `+ s_i` term).
- The amplitude term is **not** fixed-anchored in the first version; all four terms share the same
  uncertainty parameterization. If monitoring shows amplitude being neglected, an anchored fallback
  (amplitude kept at a fixed normalized weight) is documented but not enabled by default.
- Per-image manual weights become optional init-only constants, not used during the adaptive run.

## Method

For raw losses `L_amp, L_hist, L_bg, L_area` and learnable `s = (s_amp, s_hist, s_bg, s_area)`:

```
L_total = exp(-s_amp)   * L_amp
        + exp(-s_hist)  * L_hist
        + exp(-s_bg)    * L_bg
        + exp(-s_area)  * L_area
        + (s_amp + s_hist + s_bg + s_area)
```

Automatic first-step initialization: before the loop, run one forward pass, compute the four raw
losses `L_i_0`, and set `s_i <- log(L_i_0 + 1e-8)` so each weighted term starts near 1. This is
fully image-agnostic (no per-image hyperparameter).

Effective weights monitored for logging: `w_i = exp(-s_i)`.

## Design Notes

- Why jointly optimizing `s_i` with Adam is safe here (resolving `todo_0806_1.md` Phase 3B warning):
  the objective is `sum(exp(-s_i) L_i + s_i)`, not bare `sum(w_i L_i)`. The `+ s_i` regularizer makes
  driving any weight to zero increase the total loss, so collapse is impossible.
- Anchored-amplitude fallback (not enabled by default): if amplitude is observed to be neglected,
  fix `s_amp` (or fix amplitude weight to 1 after normalizing amplitude by its initial scale) and let
  only the three auxiliary terms be uncertainty-weighted. This matches the prior design principle that
  amplitude must remain a non-disablable anchor. Decide based on Task 14 monitoring.
