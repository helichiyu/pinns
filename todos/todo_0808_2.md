# TODO: 用 AL-PINNs 增广拉格朗日替换 Kendall 不确定性加权 - 2026-08-08

## 需求

`todo_0808_1.md` 实施的 Kendall 同方差不确定性加权已实测失败：`123.png` 重建塌缩成小亮点
（`support_iou` 0.117 → 0.0246）。失败机制、数学根因、已排除的省事方案见
`adaptive_weighting_research.md` 第六节；新方案的完整论证见第七节。

本 TODO 把损失组合方式从 Kendall 换成 AL-PINNs 增广拉格朗日（[arXiv:2205.01059](https://arxiv.org/abs/2205.01059)）：
**振幅为唯一目标（权重恒 1），背景与占比为不等式约束（乘子 λ 自适应），直方图为固定弱权重先验。**

四个原始损失函数本身**不变**，网络结构**不变**。

### 为什么这样能治病（对应第六节的三条诊断）

| 诊断 | AL-PINNs 的对策 |
|---|---|
| 6.5 损失无噪声下界 ⇒ `w=1/L` 不动点跑向无穷 | λ 由**违反量**驱动，约束满足则 λ 停止增长，与 `1/L` 无关 |
| 6.3 唯一抗塌缩的 area_ratio 被压成最弱项 | area_ratio 持续违反 ⇒ λ_area 单调增长，直到支撑域被撑开 |
| 6.2 amplitude 权重被牺牲（3.7e4 → 2.8e4） | amplitude 权重**恒为 1**，结构上不可能被缩放 |

## 方法

> **本节已按论文原文校正（2026-08-08）。** 初版方法节是凭一般增广拉格朗日常识写的，
> 与 AL-PINNs 原文有三处实质冲突。读到原文后全部改按论文形式，冲突记录见文末"与初版设计的偏差"。

### 论文原式（arXiv:2205.01059 式 5）

```
L_λ(θ) = ‖N u_nn - f‖        # 目标：PDE 残差
       + β ‖T u_nn - g‖²     # 罚项：β 是预先给定的固定常数
       + ⟨λ, T u_nn - g⟩     # 乘子项：λ 每步梯度上升

更新规则（论文行 299-300）：
    θ ← θ - η_θ ∇_θ L
    λ ← λ + η_λ ∇_λ L
```

### 映射到本项目

**关键观察：现有的两个二阶损失恰好就是论文的罚项**，只需为每个约束补一个一阶残差做乘子项。

| 论文 | 本项目 |
|---|---|
| 目标 `‖N u - f‖` | `L_amp`（权重恒 1） |
| 罚项 `β‖C‖²` | `β_bg · L_bg` + `β_area · L_area`（原损失函数原样复用） |
| 乘子项 `⟨λ, C⟩` | `λ_bg · r_bg` + `λ_area · r_area` |
| （论文无对应物） | `w_hist · L_hist`，统计先验按固定弱权重 |

两个一阶残差（`losses.py` 新增，不改动原有四个损失函数）：

```
r_bg   = mean((1 - contour) · pred)      # 恒 ≥ 0，为 0 当且仅当约束满足
r_area = contour.mean() - target_ratio   # 带符号：偏小为负、偏大为正
```

`r_area` 带符号这一点是**单个乘子天然双侧**的来源，推导：
占比偏小 ⇒ `r<0` ⇒ λ_area 经梯度上升变负 ⇒ 对 θ 最小化 `λ·r` 即把 `r` 推大（撑开轮廓）；
偏大则符号全部反转。**因此不需要 relu，也不需要容差 ε**——λ 在 `r→0` 时自动停止变化。
（已在 Phase 1 验证的 (c) 组用梯度符号断言过。）

### 自动标定（复用第 6.7 节保留下来的首步初始化思路）

论文的 β 靠网格搜索选取（Table B.5 取 `1e2~1e3`）。本项目改为由首次前向自动推出，
避免每张图重调——这是唯一保留自 Kendall 方案的部分：

```
w_hist  = L_amp,0 / L_hist,0        # 直方图项初始与振幅同量级
β_i     = L_amp,0 / L_i,0           # 各罚项初始等于振幅项
η_λ,i   = AL_LAMBDA_RATIO · β_i     # 乘子学习率按各自 β 成比例
λ_i     = 0                          # 论文从 0 起步
```

`η_λ` 按 β 成比例分配、而非单个标量，原因见下"与初版设计的偏差"第 4 条。

数值自检（123.png 第 1 轮实测 `L_amp,0=2.685e-5`、`L_hist,0=0.394`、
`L_bg,0=1.951e-4`、`L_area,0=0.653`），已由 `_t.py` 断言：

- `w_hist = 6.82e-5`（手调基线 `0.2/4000 = 5.0e-5`，同量级，互为印证）
- `β_bg = 0.138`、`β_area = 4.11e-5` → 两个罚项初始都精确等于 `L_amp,0` ✓
- `η_λ,bg = 1.38e-3`、`η_λ,area = 4.11e-7`
- 塌缩情形（占比停在 0.086，`r_area = -0.1015`）跑 20000 步：
  `λ_area = -8.3e-4`，`|λ·r| = 3.16 × L_amp` —— **构成抗塌缩力且未淹没目标**
- 同期罚项 `β·L_area` 只有 `0.016 × L_amp`。**λ 项才是主要抗塌缩来源**，
  这正是论文相对纯罚方法的优势（论文行 636 报告误差小约 40 倍）

### 超参清单

初版设计的 6 个超参，按论文形式**只剩 1 个**：

| 常数 | 默认 | 含义 |
|---|---|---|
| `AL_LAMBDA_RATIO` | 1e-2 | η_λ 相对 β 的比例。论文 Table B.5 最优配置 β=1e2~1e3、η_λ=1，即比例 1e-3~1e-2，本项目取上端 |

### 与初版设计的偏差（读原文后的校正）

1. **μ 不能增长**。初版写了 `μ ← μ·2` 的递增规则。论文行 171 明确批判递增罚参数
   （`β_n → ∞ ... exhibits numerical instabilities`），那正是它作为对照组的**纯罚方法**；
   行 617 说 AL-PINNs 的 `β is a predefined constant`；Remark 3.6 说大而**固定**的 β 才稳定。
   实测印证：初版的 μ 翻倍规则在 Phase 1 验证中把 λ 顶到了封顶上限。
2. **λ 每步更新，不是每 100 步**。论文行 299-300 是 θ-λ 同步的梯度上升-下降。
3. **λ 的步长是独立的 η_λ，不是 μ**。初版用 `λ ← λ + μ·c` 把两者绑在一起了。
4. **η_λ 必须按约束分别给**。论文只有一个边界约束，故单个标量 η_λ 够用；
   本项目两个约束自动标定出的 β 相差约 3300 倍（0.138 vs 4.11e-5），
   单个 η_λ 无法同时适配，故取 `η_λ,i = ratio · β_i`。**这是本项目相对论文的唯一增补**，
   已在调研文件与本节记录。
5. **容差 ε 与 relu 被消掉**。论文是等式约束、λ 不限号；带符号残差已提供双侧性，
   ε 失去存在意义。用户原本选择的"双侧约束"因此以更简的形式实现了。
6. **乘子项需要一阶残差**。`background_residual` 是背景约束的一阶度量
   （现有 `background_loss` 是二阶）。同一个约束、同一个 mask，只是 L1 vs L2 聚合，
   **不是新的先验信息**；四个原损失函数本身未改动。

## 验收标准

主判据是 **`support_iou`**，不是 PSNR——第 6.1 节已证明塌缩解的 PSNR 反而更高。

- `123.png`：`support_iou` 显著高于 Kendall 的 **0.0246**，重建不塌缩成小点。
- `567.png`：`support_iou` 不显著低于 Kendall 的 **0.853**（不退化）。
- `λ_bg` 随 `r_bg → 0` 而**趋于平稳**（这是第 6.5 节"λ 不由 `1/L` 驱动"的直接可观测证据）。
- `λ_area` 在占比偏小期间持续变负、把轮廓撑开，`r_area → 0` 后停止变化。
- `|λ_i · r_i|` 与 `L_amp` 保持同量级（1~100 倍区间）。远超则振幅目标被淹没，
  远小则约束形同虚设——两种情况都需记录并复议 `AL_LAMBDA_RATIO`。
- 四个原始损失函数与网络结构未改动。
- 任一判据不满足则**如实记录负面结果**，不强行采纳——与 Kendall 那轮同样的标准。

## 设计说明

- **为什么 histogram 不当约束**：它是统计先验而非物理硬约束，且塌缩解本身就能满足它
  （第 6.3 节），升级成约束毫无收益，只多两个超参。详见调研文件 7.4。
- **为什么 λ、β 不进 Adam**：Kendall 的失败根因之一就是 `s_i` 用 `lr=1e-4` 跟不上
  移动的不动点（第 6.2 节，滞后 400 倍）。论文的 λ 走的是**梯度上升**
  （`λ ← λ + η_λ·r`，与网络的梯度下降构成 max-min），步长与残差成正比、
  由独立的 η_λ 控制，不受网络学习率限制。β 是固定常数，本就无需优化。
- **为什么没有容差 ε**：带符号残差已提供双侧性，λ 在 `r→0` 时自动停止变化，
  容差失去存在意义。论文的约束是等式形式、λ 不限号，同样没有 ε。
- **风险：λ 无界增长**。论文 Lemma 3.5 证明"β 足够大时 ‖λ‖ 有界"，但那是在
  β 由网格搜索选定的前提下；本项目 β 是自动标定的，不保证落在该区间。
  对策是把 λ 与残差全程画进收敛图（这是本方案最重要的可观测量），
  并在验收标准里检查 `|λ·r|` 是否维持在 `L_amp` 的 1~100 倍。
  **有意不加封顶**——封顶会掩盖 β 标定不当的症状，宁可让它暴露出来。
- **风险：η_λ 比例不当**。过大则 λ 项淹没振幅目标，过小则约束形同虚设
  （即 Kendall 的失败模式重演）。`AL_LAMBDA_RATIO` 是本方案唯一的可调旋钮，
  已按 123.png 的实测残差量级验算过（塌缩情形 20000 步后 `|λ·r| = 3.16 × L_amp`）。
- **不保证优于固定权重**。`567.png` 已有可用结果，AL-PINNs 必须在 567 不退化、
  同时救回 123 才算成功。
