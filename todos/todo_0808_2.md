# TODO: 用 AL-PINNs 增广拉格朗日替换 Kendall 不确定性加权 - 2026-08-08

## 需求

`todo_0808_1.md` 实施的 Kendall 同方差不确定性加权已实测失败：`123.png` 重建塌缩成小亮点
（`support_iou` 0.117 → 0.0246）。失败机制、数学根因、已排除的省事方案见
`adaptive_weighting_research.md` 第六节；新方案的完整论证见第七节。

本 TODO 把损失组合方式从 Kendall 换成 AL-PINNs 增广拉格朗日（[arXiv:2205.01059](https://arxiv.org/abs/2205.01059)）：
**振幅为唯一目标（权重恒 1），背景与占比为不等式约束（乘子 λ 自适应），直方图为固定弱权重先验。**

四个原始损失函数本身**不变**，网络结构**不变**。

### 为什么这样能治病（对应第六节的三条诊断）

| 诊断 | AL-PINNs 的对策 |
|---|---|
| 6.5 损失无噪声下界 ⇒ `w=1/L` 不动点跑向无穷 | λ 由**违反量**驱动，约束满足则 λ 停止增长，与 `1/L` 无关 |
| 6.3 唯一抗塌缩的 area_ratio 被压成最弱项 | area_ratio 持续违反 ⇒ λ_area 单调增长，直到支撑域被撑开 |
| 6.2 amplitude 权重被牺牲（3.7e4 → 2.8e4） | amplitude 权重**恒为 1**，结构上不可能被缩放 |

## 假设与边界

- 四个原始损失函数（`normalized_log_amplitude_loss`、`soft_histogram_cdf_loss`、

## 方法

### 总损失

```
L_total = L_amp                                    # 目标，权重恒 1
        + w_hist · L_hist                          # 统计先验，固定弱权重
        + λ_bg   · c_bg   + (μ_bg  /2) · c_bg²     # 约束 1：背景
        + λ_area · c_area + (μ_area/2) · c_area²   # 约束 2：占比
```

违反量（单侧 relu，容差内不惩罚）：

```
c_bg   = relu(L_bg   - ε_bg)      ε_bg   = 0
c_area = relu(L_area - ε_area)    ε_area = (AL_AREA_TOLERANCE · target_ratio)²
```

`c_area` 是**双侧**的：`L_area = MSE(contour.mean(), target_ratio)` 天然对偏大和偏小都为正，
所以 λ_area 既阻止塌缩（占比偏小）也阻止过撑（占比偏大）。

`ε_bg = 0`：背景理论上就该全黑，无容差可言。因为 `L_bg ≥ 0` 恒成立，`c_bg = L_bg`。

### 乘子外循环（每 `AL_UPDATE_EVERY` 步一次，网络参数照常每步更新）

```
λ_i ← clamp(λ_i + μ_i · c_i, 0, λ_max_i)
若 c_i > AL_VIOLATION_DECREASE · c_i_prev:     # 违反量没有明显下降
    μ_i ← min(μ_i · AL_MU_GROWTH, μ_max_i)
c_i_prev ← c_i
```

### 自动标定（复用第 6.7 节保留下来的首步初始化思路，不引入图片相关手调值）

训练前跑一次前向，拿到 `L_amp,0 / L_hist,0 / c_bg,0 / c_area,0`：

```
w_hist    = L_amp,0 / (L_hist,0 + 1e-12)          # 直方图初始与振幅同量级
λ_i       = 0                                      # 从无惩罚起步
μ_i       = 2 · L_amp,0 / (c_i,0² + 1e-12)         # 使 (μ/2)·c₀² ≈ L_amp,0
λ_max_i   = AL_LAMBDA_MAX_FACTOR · L_amp,0 / (c_i,0 + 1e-12)   # 即 λ·c ≤ FACTOR · L_amp,0
μ_max_i   = AL_MU_MAX_FACTOR · μ_i
```

数值自检（用 123.png 已有的第 1 轮实测值 `L_amp,0 = 2.685e-5`、`L_hist,0 = 0.394`、
`L_area,0 = 0.653`、`target_ratio = 0.1875`）：

- `ε_area = (0.02 × 0.1875)² = 1.41e-5`，`c_area,0 ≈ 0.653`
- `w_hist = 2.685e-5 / 0.394 = 6.8e-5`
  （对比手调基线的 `0.2/4000 = 5.0e-5` —— 同量级，互为印证）
- `μ_area = 2 × 2.685e-5 / 0.653² = 1.26e-4`，初始约束项 `= 0.5 × 1.26e-4 × 0.426 = 2.69e-5 ≈ L_amp,0` ✓
- 若 `c_area` 一直不降，20000 轮 / 每 100 步 = 200 次更新，λ_area 线性涨到
  `200 × 1.26e-4 × 0.653 = 0.0165`，`λ·c = 0.0107`，是 `L_amp` 的约 350 倍 —— **这就是第 6.3 节缺的那股抗塌缩力**
- `λ_max_area = 1e4 × 2.685e-5 / 0.653 = 0.411`，上面的 0.0165 远未触顶，说明封顶只是兜底而非实际生效的超参 ✓
- 对比：固定权重基线收敛时 `L_area = 7.8e-7 < ε_area = 1.41e-5`，**说明这个容差不算过严**（基线是满足它的）✓

### 超参清单（全部是全局常数，不是每图参数）

| 常数 | 默认 | 含义 |
|---|---|---|
| `AL_UPDATE_EVERY` | 100 | 外循环周期 |
| `AL_MU_GROWTH` | 2.0 | μ 增长倍率 |
| `AL_AREA_TOLERANCE` | 0.02 | 占比相对容差（2%） |
| `AL_VIOLATION_DECREASE` | 0.75 | 判定"违反量未明显下降"的阈值 |
| `AL_LAMBDA_MAX_FACTOR` | 1e4 | λ·c 相对 `L_amp,0` 的封顶倍数 |
| `AL_MU_MAX_FACTOR` | 1e6 | μ 相对初值的封顶倍数 |

- `λ_area` 单调增长直到 `c_area` 落进容差。

## 设计说明

- **为什么 histogram 不当约束**：它是统计先验而非物理硬约束，且塌缩解本身就能满足它
  （第 6.3 节），升级成约束毫无收益，只多两个超参。详见调研文件 7.4。
- **为什么 λ、μ 不进 Adam**：Kendall 的失败根因之一就是 `s_i` 用 `lr=1e-4` 跟不上
  移动的不动点（第 6.2 节，滞后 400 倍）。外循环显式更新的步长由 `μ·c` 决定，
  违反越严重步子越大，不受学习率限制。
- **为什么 `ε_bg = 0` 而 `ε_area > 0`**：背景损失的理论下界是精确的 0，没有容差的物理含义；
  占比是对一个软轮廓均值的匹配，2% 相对偏差在数值上无意义（固定权重基线收敛在 `7.8e-7`，
  远小于 `ε_area = 1.41e-5`，说明该容差不构成实质放松）。
- **风险：λ 无界增长**。若 `ε_area` 过严导致约束根本不可满足，λ 会一直涨到淹没 amplitude。
  对策是 `λ_max` 封顶 + 把 λ 全程画进收敛图（这是本方案最重要的可观测量）。
- **风险：μ 过大导致震荡**。支撑域来回抖。对策是 `μ_max` 封顶。
- **不保证优于固定权重**。`567.png` 已有可用结果，AL-PINNs 必须在 567 不退化、
  同时救回 123 才算成功。
